Module Learning Outcomes

  1. Gather and format data into an actionable resource, ensuring compliance with ethical, legal and regulatory standards
  2. Investigate data using Exploratory Data Analysis (EDA) and discuss findings for decision making
  3. Implement a data cleaning and preparation plan using appropriate techniques
  4. Select and employ appropriate data engineering processes to enhance insight and scope
  5. Communicate the properties of data using a Data Dictionary (Qualitative, Quantitative, Data Type, Feature Type, etc.)
  6. Demonstrate a project cycle with verifiable ongoing progress, incorporating stakeholder feedback

Lectures

Four lectures, in reading order.

Lecture 1

Introduction to Data Exploration

What data actually is, variables/observations/attributes, data types, primary vs. secondary data, acquiring data, and version control with Git & GitHub.

Read → Lecture 2

Data Management & EDA

The data lifecycle, consistency, data dictionaries, data quality, legal/ethical constraints (GDPR), statistical properties, and univariate/bivariate/multivariate analysis.

Read → Lecture 3

Exploratory Data Analysis

EDA's purpose and methods, handling data-quality issues, and the two frameworks that structure an analytics project: CRISP-DM and SEMMA.

Read → Lecture 4

Data Cleaning

Missing data, the cleaning workflow, dropping vs. imputing vs. flagging values, and a worked example spotting problems row by row in a tiny dataset.
